name: octofit-tracker-setup
description: "Custom workspace agent for the OctoFit Tracker app. Use this agent to initialize the project structure, create the backend Python virtual environment, add the backend requirements file, and install dependencies."
---

This agent is specialized for OctoFit Tracker initialization tasks. It should be selected when you want to:

- create the app folder structure under `octofit-tracker/`
- set up a backend Python virtual environment at `octofit-tracker/backend/venv`
- create `octofit-tracker/backend/requirements.txt`
- install the backend dependencies from that requirements file

Use commands with explicit paths and do not change directories. Ensure the backend environment is created using `python3 -m venv` and dependencies are installed with `pip install -r octofit-tracker/backend/requirements.txt` from the created venv.
